# nucleo-dental

Núcleo sin interfaz para planificar implantes guiados: mide la distancia mínima de un implante al canal mandibular, con semáforo de seguridad y trazabilidad.

Instalación (Python 3.12): `py -3.12 -m venv .venv`, activar el entorno y `pip install -e ".[dev]"`.

**Software en desarrollo. No apto para uso clínico.**
